# 专题

[教程](../learn-faio.md)带你从头搭建一个异步服务。这一组专题则各自独立，围绕一个具体的工程问题展开：怎么把同步代码接进来，怎么让服务干净地停下来，错误该怎么处理，日志怎么用，异步代码怎么测。

每一篇都可以单独读，不需要按顺序。

| 专题 | 解决的问题 |
| --- | --- |
| [同步与异步桥接](bridging.md) | 已有同步代码怎么办？`block_on()` 和 `spawn_blocking()` 该怎么选 |
| [优雅停机](shutdown.md) | 怎么通知所有任务退出，又怎么等它们收尾 |
| [错误处理](errors.md) | `expected` 和异常两条通道的边界在哪里 |
| [日志](logging.md) | 在并发任务里记录诊断信息 |
| [单元测试](testing.md) | 怎么给协程代码写稳定的测试 |

碰到术语不清楚，看[术语表](../glossary.md)。想查具体接口，看[API 介绍](../api/index.md)。
